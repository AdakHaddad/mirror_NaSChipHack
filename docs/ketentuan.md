# Ketentuan Panitia

Ringkasan ketentuan Hackathon Deeptech 2026: Designing Chips for Real-World Impact, dari poster dan FAQ Peserta ICDeC ITB.

## Perangkat

- **Dari panitia.** AMD Kria KV260 dengan SD card 16 GB (satu unit per tim), function generator, osiloskop, multimeter, power supply, breadboard, kabel jumper, PCB lubang, LED, resistor, push button, dan alat solder. Board FPGA wajib memakai yang disediakan panitia.
- **Komponen tambahan.** Sensor atau modul lain disiapkan dan dibiayai tim sendiri. Komponen dapat dibawa langsung atau dikirim ke ICDeC, ITB Innovation Park Technopolis Lt. 7, Jalan Bulevar Raya No. 3, Cisaranten Kidul, Gedebage, Bandung 40295, dengan tulisan "Hackathon Deeptech 2026 – Tim NaS". Paket harus tiba sebelum 21 Oktober 2026, dan nomor resinya dikabarkan ke admin.
- **Input dari data.** Bila sensor tidak dapat disiapkan, input boleh diganti dataset atau data rekaman. Syaratnya, data dan cara pembacaannya menyerupai sensor asli, disebutkan di README dan saat pitching bahwa input berasal dari data, dan PoC tetap terbukti berjalan. Demo dengan sensor live tetap lebih disarankan.

## Output dan Penilaian

- **Proof of Concept.** Desain chip atau sistem yang berfungsi di FPGA atau simulasi, serta evaluasi kinerja (akurasi, latensi, *throughput*).
- **Business model.** Rencana komersialisasi, target pengguna dan pasar, nilai tambah, strategi implementasi, serta proyeksi dampak.
- **Materi pitching.** Slide untuk Demo Day.
- **Juri.** Akademisi, perwakilan industri, dan mitra ekosistem.
- **Kriteria.** Inovasi, kelayakan teknis, dampak nyata, dan potensi implementasi.
- **Hadiah.** Total Rp100 juta, ditambah kunjungan ke industri semikonduktor di Belanda untuk seluruh anggota tim pemenang.
